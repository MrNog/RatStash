# Contributing to RatStash

Ideas and fixes are welcome. Changes go through **pull requests** to this repository; please don't
publish your own modified version (see [LICENSE](LICENSE)).

1. **Open an issue first** for anything bigger than a small fix, so we can agree on it before you
   spend time on it.
2. **Fork** the repository, make your change on a branch, and open a pull request.
3. Keep it to **WoW 3.3.5a** (Interface 30300): no API from later expansions (`SetShown`,
   `C_Container`, …).
4. Test it in game (bags, bank and the settings window) and say in the pull request what you tried.
5. Match the code around it: same naming, same comment style, no debug prints left behind.

By opening a pull request you agree that your change can be used and published as part of RatStash
under its [license](LICENSE). The author decides what gets merged.

Found a bug? Open an issue with what you did, what you expected and what happened (a screenshot or
the Lua error text helps a lot).
